## 弹窗高度撑满屏幕修复（本回合）
- 现象：机器人「添加通道」弹层上下顶满屏幕。根因是共享 `ui-primitives` 的 `Modal.module.css` 里 `.dialog` 无 `max-height`，高度跟随内容；机器人表单（3 输入框 + 5 预设卡片说明）超过视口时即被撑满。
- 修复：不改动共享组件，利用 Modal 自带的 `className`/`contentClassName` 扩展点，在 `DingtalkConfig.tsx` 传给 Modal；`MyDemo.module.css` 新增 `.modalDialog { max-height: calc(100vh - 48px) }`（减去 Modal.root 的 24px 内边距）与 `.modalContent { flex: 1 1 auto; min-height: 0; overflow-y: auto }`（内容区滚动、footer 固定）。
- 注意 `exactOptionalPropertyTypes`：CSS module 值为 `string | undefined`，传给可选 prop 需 `?? ''`。
- 验证：tsc 通过、bundle 成功。
